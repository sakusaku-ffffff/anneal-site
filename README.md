# Anneal — 公開ページ

タスク管理アプリ **Anneal** のプライバシーポリシーを置くためのリポジトリ。

| ファイル | 中身 |
|---|---|
| `index.html` | プライバシーポリシー（日本語・英語。1枚で完結。外部フォント／スクリプトの読み込みは0） |

GitHub Pages で公開し、そのURLを次の2か所に登録する。

- Google Cloud Console → OAuth 同意画面 → プライバシーポリシーのURL
- Microsoft Store → 提出 → プロパティ → プライバシーポリシーのURL

## 注意

このリポジトリは **Anneal 本体とは別のリポジトリ**にしてある。本体のフォルダには
OAuth クライアントの JSON が入っているので、まとめて公開すると一緒に出てしまう。

## 更新のしかた

`index.html` を書き換えて push すると、数十秒で公開ページに反映される。
本文を変えたら、冒頭の「最終更新日 / Last updated」も一緒に直すこと。
